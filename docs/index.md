# eduHarness 使用手冊

給教師的 AI 教學技能包。你不需要會寫程式，也不需要背指令——用平常講話的方式告訴 AI 你要什麼就好。

還沒安裝？先看專案首頁的[安裝一節](../README.md#安裝約-5-分鐘)，大約五分鐘。

## 我今天想做的事

| 我要… | 看這篇 |
|---|---|
| 備一堂課 | [出一份教案](how-to/write-lesson-plan.md) |
| 出考題 | [出一份題庫](how-to/build-item-bank.md) |
| 讓不同程度的學生都跟得上 | [把現有教案分層](how-to/differentiate-lesson.md) |
| 把教材變成闖關遊戲 | [教材轉闖關遊戲](how-to/material-to-game.md) |
| 交數位學習精進的教案 | [數位學習精進格式教案](how-to/digital-learning-plan.md) |
| 規劃角色、場景或分鏡 | [美工與八格分鏡](how-to/art-and-storyboard.md) |

第一次用？先走一次 [15 分鐘做出你的第一份題庫](tutorial/first-item-bank.md)。走完你就知道整套怎麼運作，之後查上面的表格就夠了。
