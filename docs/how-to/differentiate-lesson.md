# 教案差異化教學

把一份既有教案改寫成分層支持的版本,核心目標不會因此降低。用的是「教案差異化」技能。

## 開始前準備

**一份既有教案或明確來源**——這是這個技能最重要的前提。如果你沒有教案,只是想從課綱開始寫,它會提醒你這其實是「教案撰寫」的工作,不會憑空生一份教案再幫你分層。

準備好之後還需要:科目、核心目標與評量、學習者差異／先備狀況、要分幾層、可用時間與設備、語言或可及性需求、補救與延伸的限制。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 把既有教案交給它

檔案拖進對話,或把教案內容貼上。Word、PDF 會先轉成純文字再讀,細節見[讓 AI 讀 Word／PDF](convert-documents.md)。

### 3. 說出你要什麼

講清楚這幾項,它就不會反問:

```
這是我這份五年級自然科教案,幫我做差異化。
班上有 3 位理解較慢、2 位程度超前的學生。
分三層:基礎、一般、延伸,核心目標與評量標準不能降低。
時間跟設備跟原教案一樣,沒有特殊語言需求。
```

完整的必填項目:既有教案、科目、核心目標與評量、學習者差異／先備、分層數量、可用時間／設備、語言／可及性需求、補救與延伸限制。

### 4. 補齊它問的缺件

沒有來源教案或關鍵資訊不足時,它會先停下來說明缺什麼,不會自己捏造一份教案再分層。

### 5. 檢查差異化後評量是否還對得上核心目標

拿到草稿先看 `artifact-alignment-report.md`——它告訴你分層之後,評量還能不能對應到原本的核心學習目標,公平性有沒有疑慮。

## 它會在什麼時候停下來

這些不是故障,是刻意的:

- **沒有既有教案或明確來源** → 提醒你先去用[教案撰寫](write-lesson-plan.md),不會憑空生教案。
- **差異化後評量對不上核心目標,或公平性有疑慮** → 停下來,不會直接交付。
- **學科迷思概念、易錯概念、鷹架理論沒有來源證據** → 只標「待確認」,不會把推測寫成定論。
- **核心學習目標或評量標準因分層而被默默降低** → 這是這個技能絕對不做的事,below 層只增加支援、不降低標準。

## 常見狀況

**「它說要我先給教案」**
對,這個技能一定要有既有教案或明確來源才能做差異化。沒有的話請先用[教案撰寫](write-lesson-plan.md)。

**「分層之後程度好的學生會不會學得比較少」**
不會。核心學習目標與評量標準不因分層而降低,調整的只有支持的多寡,不是目標的高低。

**「它把某個迷思概念標成待確認」**
因為缺乏來源證據,它不會替你把學科事實編成定論。看到「待確認」代表這一段需要你自己核對或補來源。
