# 寫一份教案

把課綱、學習者狀況與節數限制轉成完整教案草稿。用的是「教案撰寫」技能。

## 開始前準備

**課綱或教材範圍**、**學習者狀況**(先備知識、學習差異)與**評量目的**(形成性還是總結性)——這三樣缺一樣,AI 會先停下來要你補,不會自己編。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 把課綱或教材交給它

檔案直接拖進對話,或把課綱文字貼上。Word、PDF 這類檔案會先轉成純文字再讀,細節見[讓 AI 讀 Word／PDF](convert-documents.md)。

### 3. 說出你要什麼

講清楚這幾項,它就不會反問:

```
用這份自然科課綱幫我寫一份五年級教案,共 3 節課。
先備知識是四年級的水循環概念,教室有投影設備但沒有平板。
班上有 2 位閱讀理解較弱的學生需要額外支持。
評量目的是形成性,用課堂觀察加小測驗,交付格式用表格。
```

完整的必填項目:學段／年級、科目、節數、先備知識、教材範圍、核心素養／學習目標、可用設備、學習者差異、評量目的、評量方式與限制、交付格式與來源。

### 4. 補齊它問的缺件

少了關鍵項目時,它會先給你一份 `intake-gap.md` 列出缺什麼,**不會先生成教案**。補上之後再說一次就好。

### 5. 檢查目標與活動、評量是否對得起來

拿到草稿先看 `objective-activity-assessment-matrix.md`——它告訴你每個學習目標有沒有對應的活動與評量,有沒有目標漏掉沒被評到。這一步比從頭讀教案快得多。

## 你會拿到什麼

不是一段文字,是一組檔案:

| 檔案 | 內容 |
|---|---|
| `context-brief.md` | 這份教案的背景摘要——學段、科目、節數、來源 |
| `standards-alignment.md` | 核心素養／學習目標與課綱的對齊狀況 |
| `objective-activity-assessment-matrix.md` | 目標 × 活動 × 評量的對應矩陣 |
| `differentiation-plan.md` | 針對學習者差異的初步調整方向 |
| `assessment-design.md` | 評量設計的整體邏輯 |
| `assessment-rubric.md` | 評分規準 |
| `differentiation-assessment-alignment.md` | 差異化調整與評量是否仍對得上目標 |
| `lesson-flow.md` | 逐節課的教學流程 |
| `materials-and-resources.md` | 需要準備的教材與資源清單 |
| `lesson-plan-draft.md` | 教案草稿本體 |
| `review-report.md` | 自我檢查結果 |

## 它會在什麼時候停下來

這些不是故障,是刻意的:

- **缺來源、目標、學習者差異或評量目的** → 只給 `intake-gap.md`,不正式產出教案。
- **沒指定當年度或地方模板** → 產通用版並標「待確認」,不冒充官方指定格式。
- **涉及學生個資、對外發布或正式送件** → 停下來等你核准。
- **你其實已經有一份教案,只是想調整** → 會提醒你這其實是「教案差異化」,不會重新從零生一份。

## 常見狀況

**「它要我填的東西好多」**
一次把必填項目講完就不會反覆問。照第 3 步那段的格式寫,通常一次過。

**「我要的是官方指定的那個格式」**
沒指定當年度或地方模板時,它會產通用版並標「待確認」——這是提醒你送出前自己核對官方公告,不是它偷懶。

**「我已經有教案了,只想調整」**
那不是這個技能的工作範圍,要用[教案差異化教學](differentiate-lesson.md)——它會保留你原本的核心目標,只調整支援層級。
