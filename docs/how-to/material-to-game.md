# 把教材轉成闖關遊戲

把教材轉成實體或網頁闖關遊戲的規格。用的是「教材轉闖關遊戲」技能。

注意:它產出的是**規格**,不是做好的遊戲程式或美術素材。拿到規格之後,還要另外找人或工具實作。

## 開始前準備

**先想好要哪個分支**:實體、網頁,或兩者都要。沒有指定分支,它只會給你一份缺件報告,不會自己幫你選網頁版。

還需要:教材／來源、學段與年齡、學習目標、場域／設備、時間、玩家人數、可及性需求、評量方式與資產限制。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 把教材交給它

檔案拖進對話,或把內容貼上。Word、PDF 會先轉成純文字再讀,細節見[讓 AI 讀 Word／PDF](convert-documents.md)。

### 3. 說出你要什麼

講清楚這幾項,它就不會反問:

```
用這份社會科教材幫我設計一個網頁闖關遊戲。
四年級、20 人一組、40 分鐘、教室有平板可以用。
學習目標是認識家鄉的地理特色,沒有特殊可及性需求。
評量用闖關過程中的答題正確率,不需要外部素材授權。
```

完整的必填項目:教材／來源、學段與年齡、學習目標、遊戲分支(實體／網頁／兩者都要)、場域／設備、時間、玩家人數、可及性需求、評量方式與資產限制。

### 4. 補齊它問的缺件

分支、學習目標或教材沒講清楚時,它只給缺件報告,不會自己出完整規格。

### 5. 檢查安全與可及性審查

拿到規格先看 `accessibility-and-safety-review.md`——尤其是實體活動,確認有沒有尖銳物、小零件、移動或競賽風險被標出來。

## 它會在什麼時候停下來

這些不是故障,是刻意的:

- **沒指定分支、學習目標或教材** → 只給缺件報告,不出完整規格。
- **實體活動有尖銳物、小零件、移動或競賽風險** → 停在年齡／安全 Gate,等你確認怎麼處理。
- **完成規格不等於完成遊戲** → 規格做完不會自動變成能玩的程式、素材或部署,那是下一步的工作。
- **場景有具名角色、重複場景、連續動作、Boss 或事件演出、鏡頭轉場** → 只提醒你一次可以用[美工與八格分鏡](art-and-storyboard.md),不用也不影響遊戲設計繼續進行。

## 常見狀況

**「它問我要實體還是網頁」**
一定要先選,兩種產出差很多——實體要顧場地與安全,網頁要顧介面與素材規格。選好之後才會出完整規格。

**「它問我要不要做分鏡」**
那只是個選項,提醒一次而已。不想要就直接略過繼續,不影響遊戲設計本身。想做的話看[美工與八格分鏡](art-and-storyboard.md)。

**「它給我的是規格不是遊戲」**
對,這個技能產的是設計規格,不是成品。規格拿到之後,做成真正能玩的遊戲或素材是接下來的工作。
