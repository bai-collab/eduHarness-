# 出一份題庫

把課綱或教材轉成可以審查的題目草稿。用的是「試題命題」技能。

## 開始前準備

**一份教材來源**——課綱段落、課本頁面、講義檔案都可以。沒有來源，AI 會停下來要你補，不會自己編題目。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 把來源交給它

檔案直接拖進對話，或把課綱文字貼上。Word、PDF 這類檔案會先轉成純文字再讀，細節見[讓 AI 讀 Word／PDF](convert-documents.md)。

### 3. 說出你要什麼

講清楚這幾項，它就不會反問：

```
用這份自然科課綱幫我命 20 題選擇題。
六年級、四選一、每題附正確答案與解析。
指標範圍以課綱第三章為準，難度中等，交付格式用表格。
```

完整的必填項目：學段、科目、來源、題數、題型、學習指標範圍、難度、答案格式、使用語言、要不要人工審查。

### 4. 補齊它問的缺件

少了關鍵項目時，它會先給你一份 `intake-gap.md` 列出缺什麼，**不會先生成題目**。補上之後再說一次就好。

### 5. 檢查 coverage matrix

拿到草稿先看 `coverage-matrix.md`——它告訴你每個指標各出了幾題、有沒有指標一題都沒涵蓋到。這一步比逐題看快得多。

## 你會拿到什麼

不是一段文字，是一組檔案：

| 檔案 | 內容 |
|---|---|
| `indicator-checklist.md` | 指標清單與對齊狀況 |
| `source-ledger.md` | 每筆來源的檔名、日期、版本、授權狀態 |
| `coverage-matrix.md` | 指標 × 題目的涵蓋矩陣 |
| `item-blueprint.md` | 題型、認知層次、難度的配置 |
| `item-bank-draft.md` | 題目草稿本體 |
| `review-report.md` | 自我檢查結果 |
| `human-review-brief.md` | 交人工覆核時要看什麼 |

每題都保留來源定位與人工覆核欄位——這是為了讓你能追「這題是從哪一段出的」。

## 它會在什麼時候停下來

這些不是故障，是刻意的：

- **缺學段、科目、來源或指標** → 只給缺件報告，不正式命題。
- **你問的是官方規範，但沒有官方證據** → 標成「待確認」，不會把模型推測寫成官方說法。
- **涉及學生個資、未授權題庫、對外發布或正式評量** → 停下來等你核准。

## 常見狀況

**「它一直要我補資料，很煩」**
把必填項目一次講完就不會了。照第 3 步那段的格式寫，通常一次過。

**「出來的題目重複」**
重複題與自相矛盾的題目它會先標記出來，不會默默留著。看 `review-report.md`。

**「我要的是整份考卷排版」**
這個技能產的是題庫草稿，不管版面。排版是另一件事，你拿到 `item-bank-draft.md` 之後再處理。

**「我想改它的命題規則」**
規則寫在 `brain/skills/item-authoring/SKILL.md`，可以改，但改完要重新投影——見[改技能並重新投影](edit-a-skill.md)。
