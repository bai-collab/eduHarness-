# 美工與八格分鏡

規劃美術方向、角色、場景、素材提示詞,以及可選的八格連續分鏡。用的是「美工與八格分鏡」技能。

## 開始前準備

有兩件事很容易搞混,先講清楚:

- **分鏡預設是關閉的。** 只要角色或場景美術,直接描述需求就好,不必啟用分鏡。要做八格分鏡才輸入 `/gb`。
- **`/gb` 跟 `/Hyperframes` 不是同一件事。** `/gb` 是圖片分鏡規劃,`/Hyperframes` 是影片流程,不屬於這個技能,兩者不會混用。

還需要:用途、受眾、媒介、風格、尺寸／比例、角色與場景限制、既有參考素材。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 描述你要的美術方向

檔案(既有參考素材)可以直接拖進對話,或用文字描述。

### 3. 只想要角色或場景設計,直接講需求

```
幫我設計一個國小自然科教材裡的主角,是一位年輕的森林嚮導,
風格走可愛插畫風,用於網頁闖關遊戲的角色圖示,直向比例。
沒有既有參考素材,場景限制是需要能在森林跟教室兩種場景出現。
```

### 4. 需要八格分鏡才輸入 `/gb`

```
/gb
幫我規劃這個森林嚮導遇到迷路小朋友、帶他找到指標、
最後成功回到教室的八格分鏡,風格延續前面設計的角色。
```

輸入 `/gb` 之後,它才會啟動八格分鏡規劃,預設用 2×4 呈現,每格標景別、鏡頭方向／運動、角色動作、場景變化、敘事目的與銜接點,並固定角色外觀與空間軸線——不是把八張無關的圖硬拼在一起。

### 5. 檢查角色一致性錨點與鏡頭連續性

做了分鏡之後,看角色一致性錨點與鏡頭連續性檢查——確認角色在八格裡外觀沒有跑掉,鏡頭銜接合理。

## 你會拿到什麼

依你有沒有輸入 `/gb`,拿到的東西不一樣:

**art-only(預設,沒有輸入 /gb)**

| 檔案／內容 | 說明 |
|---|---|
| 美術方向 | 整體風格與調性描述 |
| 角色／場景規格 | 角色與場景的設定細節 |
| 資產清單 | 需要準備的美術資產列表 |
| 生成提示 | 可交給圖片生成工具使用的提示詞 |

**storyboard-on(輸入 /gb 之後,在 art-only 之外另外加上)**

| 檔案／內容 | 說明 |
|---|---|
| 八格分鏡表 | 2×4 呈現,每格標景別、鏡頭方向／運動、角色動作、場景變化、敘事目的、銜接點 |
| 角色一致性錨點 | 固定角色外觀,避免八格之間角色跑掉 |
| 鏡頭連續性檢查 | 確認空間軸線與鏡頭銜接合理 |
| 完整生成提示 | 可直接交給圖片生成工具使用的八格提示詞 |

## 它會在什麼時候停下來

這些不是故障,是刻意的:

- **要求影片、補幀或動態生成** → 停在分鏡與提示交接的地方,不會自行啟動 `/Hyperframes`。
- **環境沒有圖片生成工具** → 只交付提示詞與規格,不會宣稱已經幫你產出圖片。
- **教育內容只靠顏色傳達關鍵資訊** → 會提醒避免這麼做,因為不利於色覺差異的學生閱讀。

## 常見狀況

**「我只要角色設計,不要分鏡」**
直接講需求就好,分鏡預設關閉,不用特別說「不要分鏡」。

**「/gb 跟 /Hyperframes 有什麼不同」**
`/gb` 是圖片的八格分鏡規劃,`/Hyperframes` 是影片流程的技能,兩者處理的媒介不同,不會混用。

**「它沒有幫我畫出來」**
如果你目前的環境沒有接圖片生成工具,它只會給你完整的提示詞與規格,不會宣稱已經產圖——提示詞就是給你拿去生成工具用的。
