# 寫一份數位學習精進教案

用台灣數位學習精進方案的格式產出教案,含平台佐證、師生操作矩陣、學習證據與隱私揭露。用的是「數位學習精進教案」技能。

## 開始前準備

**既有教案或課程脈絡**、**要用的數位平台**,以及**送件格式的來源與日期**——這三樣是它判斷要用哪種格式骨架的依據。

還需要:學段／科目／節數、學習目標、教師／學生操作方式、設備與網路條件、評量與學習證據、隱私／AI 揭露需求。

## 步驟

### 1. 用 Claude Code 開啟 eduHarness 資料夾

### 2. 把既有教案或課程脈絡交給它

檔案拖進對話,或把內容貼上。Word、PDF 會先轉成純文字再讀,細節見[讓 AI 讀 Word／PDF](convert-documents.md)。

### 3. 說出你要什麼

講清楚這幾項,它就不會反問:

```
用這份既有教案幫我寫數位學習精進方案的教案,六年級數學、2 節課。
使用平台是 Google 表單跟均一教育平台,教室每人一台平板、網路穩定。
評量用平台作答紀錄當學習證據,需要 AI 使用揭露。
目前沒有指定今年度的徵件模板,先用通用版。
```

完整的必填項目:既有教案或課程脈絡、學段／科目／節數、學習目標、數位平台、教師／學生操作、設備與網路條件、評量與學習證據、profile 來源與日期、隱私／AI 揭露需求。

### 4. 補齊它問的缺件

平台功能、profile 年度或來源不清楚時,它會先列出缺什麼,不會自己套用舊格式或假設今年度規格。

### 5. 核對格式差異報告

拿到草稿先看格式差異報告——它告訴你這份用的是通用骨架還是你指定的年度模板,兩者差在哪裡。

**重要提醒:未確認的年度格式,不是既定事實。** 沒有指定當年度或地方徵件模板時,它會產出通用版並標記「待確認」。這份草稿拿去正式送件前,你一定要自己核對當年度教育部或地方公告的最新徵件規格——技能本身不會替你保證這份符合今年度的官方要求。

## 它會在什麼時候停下來

這些不是故障,是刻意的:

- **未確認 profile、年度或來源** → 不套用舊格式,不宣稱符合當年度徵件規格,只出通用版並標「待確認」。
- **平台功能、版本、個資或 AI 使用缺乏證據** → 輸出待確認欄位,不替你保證平台做得到什麼。
- **正式送件、外部上傳、學生個資處理** → 停下來等你核准。

## 常見狀況

**「它產的格式是今年的嗎」**
沒有指定的話就是通用版,標「待確認」。送件前你要自己核對當年度的官方公告,這不是它偷懶。

**「它要我揭露 AI 使用」**
因為這涉及學生隱私與資訊揭露規範,這是刻意設計的一步,不是多餘的手續。

**「平台功能它標了待確認」**
因為缺乏證據,它不會替你保證某個平台一定做得到某項功能——這一格待確認就是提醒你自己去確認平台的實際版本與功能。
