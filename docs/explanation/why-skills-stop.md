# 為什麼技能會停下來要你補資料

你會遇到這種情況：交代一件事給 AI，它不但沒開始做，反而回你一份「還缺這些」的清單，或是做到一半停下來要你確認。

**這不是故障，是設計。** 每個技能都有「停止規則」，這頁解釋它們為什麼存在。

## 停止，是在幫你省更大的成本

### 資料不足時，它只給缺件清單

如果課綱、學段、題數這些關鍵資訊不齊，技能不會硬生出一份東西，只會給你一份 `intake-gap.md` 列出缺什麼。

為什麼？因為**它編出來的內容，錯了得你自己抓**。一份看似完整、其實建立在猜測上的教案或題庫，比一句「你還沒告訴我學段」危險得多——後者你馬上知道要補什麼，前者你可能用到一半才發現方向全錯。

### 沒有官方證據時，它不敢稱官方

當你問的東西牽涉當年度或地方規範，而它手上沒有官方來源，它會把內容標成「待確認」，不會把模型的推測寫成官方說法。

為什麼？因為**送件被退的代價由你承擔**。它寧可明講「這是通用版、請自行核對當年度公告」，也不冒充一個它其實不確定的格式。

### 碰到個資、對外發布、正式評量，它停在核准閘門

涉及學生個資、要對外發布、或用於正式評量時，技能會停下來等你明確同意才繼續。

為什麼？因為這些動作**不可逆或有後果**。多問你一次的成本很低，替你做錯決定的成本很高。

## 反過來說：它不該一直停

停止規則是為了在**資訊不足**時保護你，不是為了刁難。如果你已經把該給的都給了，它卻還一直問，通常是**你漏了某個必填項目**，不是它壞了。

最快的解法：打開對應的[操作指南](../index.md#操作指南--這件事怎麼做)，照「開始前準備」和步驟裡那段提示詞範例把資訊一次講完。多數「它一直問」的狀況，補齊必填項目就消失了。

## 為什麼不設計成「有多少做多少」

「先做出個大概，再讓我補」聽起來更順，但對教學材料特別危險：一份填滿了合理猜測的教案或題庫，表面上可用，錯誤卻藏在細節裡。教師不一定有時間逐項驗證，於是猜測就這樣進了課堂或考卷。停下來問，是把「發現缺什麼」這件事提前到你還沒投入信任之前。
