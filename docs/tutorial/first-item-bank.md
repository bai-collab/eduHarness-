# 15 分鐘做出你的第一份題庫

這是一次帶著做的練習。走完你會得到一份真的題庫草稿，也會親眼看到這套技能怎麼運作——包括它為什麼會中途停下來問你。

跟著做就好，先不用理解每一步的原理。原理在[概念](../index.md#概念--為什麼這樣設計)那幾頁。

## 你需要

- 已經裝好 Claude Code 並下載了 eduHarness（見[安裝](../../README.md#安裝約-5-分鐘)）。
- 一小段課綱或課文——**兩三段就夠**，這是練習，不用整本。

## 第 1 步：開啟資料夾

用 Claude Code 開啟 eduHarness 這個資料夾。開好後，這一整套技能就都在它眼前了，你不用做任何載入動作。

## 第 2 步：先故意講不清楚

這一步是**刻意的**。先只講一半，看看會發生什麼：

```
幫我出幾題考題。
```

它不會開始出題。它會回你一份**缺件清單**，告訴你還少了學段、科目、來源、題數、題型這些關鍵資訊。

**這不是壞掉。** 這是設計好的行為——資料不夠時它寧可停下來問，也不會自己編一份你還得回頭抓錯的題目。記住這個感覺，之後你會常常遇到。

## 第 3 步：這次講清楚

把缺的補齊，一次講完：

```
用我貼的這段自然科課文幫我命 8 題選擇題。
六年級、四選一、每題附正確答案與解析，難度中等，交付格式用表格。
```

然後把你的課文貼上，或把檔案拖進對話。這次它就會開始工作了。

> Word 或 PDF 檔它會先轉成純文字再讀。你只管拖進去，細節見[讓 AI 讀 Word／PDF](../how-to/convert-documents.md)。

## 第 4 步：先看涵蓋矩陣，不要先看題目

拿到一堆檔案後，先打開 `coverage-matrix.md`。

它用一張表告訴你：每個學習指標各出了幾題、有沒有哪個指標一題都沒涵蓋。**這比你逐題讀快得多**，也是判斷這份題庫夠不夠均衡的最快方法。

## 第 5 步：看題目本體

打開 `item-bank-draft.md`，這才是題目。每一題都附了答案、解析，還有一個「來源定位」欄位——告訴你這題是從你給的哪一段出的，方便你核對。

如果有重複或自相矛盾的題目，它已經幫你標記出來了，看 `review-report.md`。

## 你完成了

你現在有一份題庫草稿，而且知道了三件事：

1. 資料不夠時它會停下來問，不會亂編。
2. 產出是一組檔案，不是一段文字。
3. 先看 `coverage-matrix.md` 最省時間。
