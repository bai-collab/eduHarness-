## 二、設計依據

### 核心素養 Core competency（總綱／領域／群科，視課程性質選用）

- 1. 自主行動
  - □ E-A1 具備良好生活習慣並促進身心發展。
  - □ E-A2 具備探索問題的思考能力。
  - □ E-A3 具備擬定計畫與實作的能力。
- 2. 溝通互動
  - □ E-B1 具備符號知能，能以同理心應用在溝通。
  - □ E-B2 具備科技與資訊應用的基本素養。
  - □ E-B3 具備藝術創作與欣賞的基本素養。
- 3. 社會參與
  - □ E-C1 能理解並遵守社會道德規範與公民素養。
  - □ E-C2 樂於與人互動、團隊合作。
  - □ E-C3 關心本土與國際事務，包容多元文化。

### 數位素養

- 1. 數位公民
  - □ a. 自我成長：健康的科技工具使用習慣，並自主學習。
  - □ b. 媒體識讀：能理解數位安全及媒體的影響力。
  - □ c. 公民道德：能以合法、安全的方式使用科技。
- 2. 數位共好
  - □ a. 溝通表達：能運用適當之數位工具或平台與他人分享。
  - □ b. 包容協作：能用數位工具與他人溝通，並同理他人。
  - □ c. 文化尊重：能用數位工具理解文化的多元性。
- 3. 數位創新
  - □ a. 問題解決：能探索思考，並用適當的策略解決生活問題。
  - □ b. 思辨創造：能使用工具擬定策略並嘗試執行計畫。
  - □ c. 美感生活：能將美感元素融入數位作品，並培養美感。

| 檢核項目 | 說明 | 勾選 | 生成式 AI 運用 |

| 小組合作 | 設計小組合作活動，促進學生間的互動與協作學習。 |  |  |
| 即時反饋 | 透過數位工具即時檢視並反饋學生的學習狀況，進行差異化之教學。 |  |  |

### 課後評量

| 檢核項目 | 說明 | 勾選 | 生成式 AI 運用 |
| :-- | :-- | :-: | :-: |
| 學習回饋 | 收集學生的學習成果，並進行分析與評價。 |  |  |
| 多元評量 | 採用多元評量方式，如口說辨識結果、互動問答記錄、成果發表等，全面評估學生學習成效。 |  |  |
| 改進計劃 | 根據評量結果，制定後續教學改進計劃，提升教學質量與學生學習成效。 |  |  |
| 反思與調整 | 反思教學過程，根據實際情況進行教學策略的調整與改進。 |  |  |
| 長期跟進 | 持續跟進學生的學習進度和成效，提供持續性支持和指導。 |  |  |
