# 海明威寫作法

## 核心原則

> 📖 白話：不要「說」感覺，要「演」給讀者看。刪掉副詞和抽象形容詞，用具體的動作、物件、數字讓畫面自己說話。

利用 AI 寫文章時，禁止它使用副詞與抽象形容詞，文字會立刻變得有畫面感。這就是海明威寫作法：

1. **禁用副詞**——尤其是修飾動詞的程度副詞：「非常」「十分」「極其」「真的」「慢慢地」「靜靜地」等。動詞本身要選得夠準，不需要副詞撐腰。
2. **禁用抽象形容詞**——「美麗的」「重要的」「驚人的」「溫馨的」這類詞是作者的結論，不是讀者的體驗。把結論換成可觀察的細節。
3. **Show, don't tell**——把情緒與評價翻譯成動作、物件、聲音、數字。

## 改寫對照

| 禁用寫法（tell） | 海明威寫法（show） |
|---|---|
| 她非常生氣。 | 她把筷子拍在桌上，碗裡的湯濺了出來。 |
| 那是一棟很美麗的老房子。 | 紅磚牆爬滿藤蔓，木門推開時鉸鏈叫了一聲。 |
| 他跑得非常快。 | 他衝過終點時，第二名還在三十公尺外。 |
| 這個功能極其重要。 | 這個功能一掛，全站登入跟著停擺。 |
| 天氣冷得可怕。 | 呼出的氣在圍巾上結了一層白霜。 |

## 執行程序

寫作或改稿時依序執行：

1. **起草前宣告約束**：在寫作指令中明列「禁止使用副詞與抽象形容詞」。
2. **逐句自查**：完稿後掃描每一句——
   - 找出副詞（中文常見「地」字結尾、程度詞；英文常見 -ly 結尾），刪除或改選更強的動詞。
   - 找出抽象形容詞，改寫成具體細節：這個「美」讀者用哪個感官接收？給出那個感官的畫面。
3. **強動詞優先**：「快速地走」→「衝」；「小聲地說」→「耳語」。
4. **保留必要的限定詞**：技術文件、法律文字、學術論文中承載精確語意的修飾語（「顯著差異」「僅限」「至少」）不在禁用範圍——本法適用於敘事、散文、文案、演講稿，不適用於需要精確量化語言的文體。

## 交付檢查

- [ ] 全文零程度副詞（「非常」「十分」「真的」…）
- [ ] 抽象形容詞已換成可觀察的細節
- [ ] 每個場景至少一個具體感官錨點（視、聽、觸、嗅、味其一）
- [ ] 動詞經過挑選，不依賴副詞補強
