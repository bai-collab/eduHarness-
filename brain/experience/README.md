# experience — 任務後的可重用經驗

放「這件事我當初怎麼想的、那個判斷哪裡不對」。

## 跟 errorLog 的分工

- `brain/errorLog/` 記**什麼壞了、根因是什麼** → 修行為。
- 本層記**我當初怎麼拆的、判斷方式哪裡有問題** → 修判斷。

同一件事可能兩層都要寫：錯誤本身進 errorLog，「為什麼我會那樣判斷」進這裡。

## 什麼時候寫

做完夠大的工作之後：預計超過三十分鐘、跨多個檔案、分成好幾個階段，或中途發生非預期的返工。

不用寫：瑣碎的、唯讀的、純問答的任務。這是建議性的習慣，不是關卡——變成儀式就沒用了。

## 怎麼寫

複製 `TEMPLATE.md`。**一定要填替代解釋與成功面**：只記失敗會讓你以為自己什麼都做錯，下次反而不敢下判斷。

本目錄目前是空的。你新增的檔案不會被 `git pull` 刪除；但本檔與 `TEMPLATE.md` 屬於內建檔，更新時會被覆蓋，別直接改它們。
