# 給使用者的指令用「…」省略，被照抄執行

- 日期：2026-10-03
- 情境：某速度改善計畫 P6，主 session 在回覆裡把真跑指令寫成 `npm.cmd run bench:live -- --policy <policy> … --budget-usd 0.10 ...`，用「…」代表「完整指令見 README」。
- 錯誤：使用者在 `<使用者家目錄>`（不是專案目錄）直接貼上執行，npm 回 `ENOENT package.json`。沒有啟動執行器、沒有花費。
- 根因：要使用者執行的指令出現省略符號，而且沒有附上 `cd` 到專案目錄的步驟。

## How to apply

1. 給使用者「要貼上執行」的指令，一律完整寫出，不用「…」或「見某檔」代替任何參數；摘要和可執行指令要分開。
2. 指令依賴工作目錄時，前面一定附上 `cd <完整路徑>` 的獨立區塊。
3. 每個區塊只放一個指令，對準使用者實際用的 shell（PowerShell）。
