# Read-Host 提示標籤被貼成 API 金鑰

- 陷阱：`Read-Host -AsSecureString "<提示標籤>"` 的引號內是提示標籤，不是輸入位置；把秘密貼進引號會以明文顯示，並可能寫進命令歷史檔。
- 發生外洩時的處置原則：撤銷並重建秘密（優先改用限定範圍與預算上限的金鑰）、清除歷史檔中的對應行與含秘密的截圖；回覆中不重述任何秘密片段。

## How to apply

1. 要使用者在終端機輸入秘密時，手冊必須明寫「哪一段原樣貼上、提示出現後才貼秘密」，並說明畫面不顯示字元是正常的。
2. 使用者提供的截圖或輸出若含秘密片段，一律視為外洩：建議撤銷，不重述、不保存、不引用片段。
3. 優先設計不需要使用者手打秘密參數的流程（例如提示框輸入），並附上只顯示 True／False 的檢查指令。
