# knowledge-base — 經審核的耐久知識

放**可重用且已驗證**的事實與結論，兩個條件都成立才准進來。被任務觸發才讀取，不會每次啟動載入。

## 跟其他層的差別

`brain/skills/` 回答「這件事怎麼做」，本層回答「這件事的事實是什麼」。一個是流程，一個是內容。

還沒驗證的推測不要寫進來——寫進來就會被當成事實引用，而且引用的人不會知道它其實是猜的。

## 一份檔案的最小要求

- 檔名用 kebab-case，看得出主題。
- 開頭一句話說明適用範圍與已知邊界。
- 有來源就註明來源與查證日期；沒有來源的結論標「待確認」。

## 寫入禁令

不儲存 secrets、tokens、cookies、credentials、私鑰，也不放學生個資。

本目錄目前是空的。你新增的檔案不會被 `git pull` 刪除；但本檔屬於內建檔，更新時會被覆蓋，別直接改它。
