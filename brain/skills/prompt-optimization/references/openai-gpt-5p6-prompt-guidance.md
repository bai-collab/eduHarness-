# GPT-5.6 Sol 提示詞指南（設計摘要）

來源：<https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6>

- 來源狀態：✅已確認；官方 OpenAI Developers 指南，檢索日期 2026-07-15。
- 適用範圍：指南討論 GPT-5.6 Sol 的提示改寫、工具說明、agent 指令與提示堆疊；本 skill 將其轉為工作區通用的提示檢查規則，不推論其他模型一定相同。
- 結果先行：先說明預期結果、成功標準、停止條件，再提供必要限制與證據；避免把每一步都預先寫死。
- 最小化提示：刪除重複規則、過時範例與不相關工具；保留真正的安全／商務／證據／權限不變量。
- 權限界線：回答、解釋、審查、診斷、規劃與修改的授權不同；外部寫入、刪除、付費、發布或擴大範圍需確認。
- 工具路由：只暴露任務相關工具；說明前置條件；獨立讀取可並行，依賴步驟要順序執行；部分或可疑結果使用有限的替代查詢。
- 證據與引用：定義證據要求；缺少證據不等於事實為否；標示來源衝突與推論，重要主張要能回到來源。
- 完成前驗證：依任務指定檔案檢查、測試、型別／lint、建置或 smoke test；不能執行時說明原因。
- 長工作回報：首次工具呼叫前提供短前言，重大階段才更新；保留目前階段與停止條件。
- 遷移策略：先以現有評估建立基準，做最小針對性修改，再重跑評估；不要一次全面重寫。

## 本工作區的採用界線

1. 這份摘要是設計參考，不取代官方頁面；需要精確原文時回到來源網址。
2. 「提示詞優化」只診斷與改寫提示，不代表已執行下游任務。
3. 模型路由、額度與 Claude／Codex 的實際可用性以 harness 執行證據為準。
