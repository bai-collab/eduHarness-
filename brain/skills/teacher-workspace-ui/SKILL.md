# 教師工作台建立

## 設定

本 Skill 不寫死網址、帳號、IP 與埠號。設定來源順序：① 工作區根目錄 `private/config/sites.local.json`（本機實際值，不上傳）→ ② `config/sites.example.json`（公開範本，只有佔位值）。值含 `<…>` 或 `example` 字樣即視為**缺值**；缺值時**停下來問使用者**，不猜、不沿用舊值。

| 設定鍵 | 用途 | 預設值 |
|---|---|---|
| `services.gas.endpoint_url` | 試算表同步用的 GAS 正式 `/exec` 網址（只在教師頁設定介面貼上，由後端保存） | 無（缺值＝不啟用試算表同步） |
| `services.ai.endpoint` | 教師端 AI 分析用的 Responses 相容端點，以 `TEACHER_AI_ENDPOINT` 環境變數傳給範本 | 無（缺值＝只用「本機摘要」） |
| `local.teacher_port` | 教師工作台本機埠號，以 `PORT` 環境變數傳給 `server.mjs` | 8080（範本內建，僅在設定缺值時用） |
| `local.student_port` | 校內學生端伺服器埠號，傳給 `scripts/school-lan.mjs configure --port` | 無（工具不提供預設，缺值就問） |
| `local.lan_ipv4` | 教師機校內 IPv4，傳給 `scripts/school-lan.mjs configure --ip` | 無（仍須用 `list` 對照本機網卡） |

金鑰、RECORD_TOKEN、教師密碼**不放設定檔**：只在教師頁設定介面輸入，由後端保存。

將教師常用的三件事放在同一工作台：找學生、看作答、決定下一步引導。先讀 [功能與資料契約](references/workspace-contract.md)；需要實作時使用 [可執行範本](assets/template/) 並讀其 [啟動說明](assets/template/README.md)。[範例圖片](references/examples.md) 呈現公開範本的假資料畫面。

## 套用到專案

1. 先確認現有紀錄來源、教師登入、AI服務及試算表接線。沿用使用者指定的服務與權限；別把示範伺服器替換成既有正式後端。資料格式不同時寫轉接層，不改原分數或虛構程式快照。
2. 版面採左側導覽／學生搜尋、中央紀錄／AI分析／設定三頁。桌面學生清單常駐，窄版由明確按鈕開關；主內容與清單分別捲動。保留44px操作目標、鍵盤焦點、長文字換行及局部程式捲動。
3. 複製範本資源到使用者指定專案，再修改品牌、資料接線與AI回應轉接。先檢查目標；已有檔案先比較、合併，避免直接覆蓋。範本只依賴Node.js內建模組，不需要安裝套件。
4. 設定介面提供API金鑰、GAS正式 `/exec` URL、RECORD_TOKEN。此公開範本token為8～200碼，前端、後端、GAS一致；留白保留既有值，清除需明確勾選。不要替既有專案降低token要求，除非使用者也指定修改該專案。
5. AI預設為「本機摘要（不呼叫AI）」。真AI由教師按送出才觸發，旁邊清楚寫出選取範圍、外傳內容與費用可能性。後端依紀錄id重取資料，回覆分直接觀察、待確認推測、教學建議及資料限制，引用能跳回原紀錄。id存在只代表引用有效，不證明模型敘述正確。
6. 用假資料驗證搜尋、篩選、最後有效成績、紀錄展開、設定保存／留白／清除、分析／引用／取消／登出。同時間戳以較後保存紀錄優先；無效、範例或評分期间程式變動不取代有效成績。驗證桌面、手機與平板，確認輸入及送出可見、無橫向溢出。
7. 需要校內其他電腦連線時，讀 [校內區網部署](references/school-lan.md)。先區分學生端與教師遠端登入；沿用原程式權限。工具可列網卡、明確保存IPv4／埠號並轉接專案自己的學生端伺服器，啟動前再查網卡；不以私人網段推定學校，不自動改防火牆。獨立範本沒有學生編輯器，不能把教師後端直接改成區網監聽。

## 不可省略的接線界線

- API金鑰和token只由後端保存及使用，不讀回瀏覽器、不寫入學生紀錄或Git；教師密碼雜湊保存。範本的服務金鑰在本機是明文，不是加密保險箱。
- 範本教師伺服器只監聽loopback；保留Host、同來源、教師工作階段檢查。學生端區網設定與教師遠端部署分開；教師遠端／雲端需HTTPS與存取控制，不能只改監聽位址就稱安全。
- 模型與學生文字用textContent顯示；不要將回覆當HTML、程式或工具指令。不要把求助次數當能力、做排名或診斷，也不改評分結果。
- 直接開HTML只預覽版型，不發API；完整功能從localhost開啟。修改後端後需重啟服務。
- 範本目前支援Responses相容的非串流JSON回覆；服務不相容時先做轉接。外部AI／GAS實测須在使用者已授權且設定完成的範圍內；別用模擬成功宣稱正式服務完成。

交付修改清單、啟動方式、假資料操作截圖、實測結果及未驗證項目。審查和公開發布依當次使用者要求進行，本技能本身不授權傳送學生資料或推送任何儲存庫。
