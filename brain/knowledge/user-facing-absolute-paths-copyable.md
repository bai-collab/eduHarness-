# 對使用者的路徑與連結：絕對路徑＋一鍵複製

## 來源

使用者於 2026-10-16（某教學動畫結案時）指出：之後的交接檔、檔案連結、網頁連結都要寫絕對路徑，並讓使用者可一鍵複製；同時要求寫入記憶與規範。

## How to apply

1. **解析路徑**：交付前用當下環境取得 repository 根目錄的絕對路徑（例如 `pwd -W`／`cygpath -w`），再接上相對路徑；Windows 上給使用者看的路徑用反斜線格式（例如 `<磁碟>:\<repo>\projects\<主題>\index.html`）。
2. **一鍵複製**：每個路徑或網址獨立一個 ```text 區塊，區塊前用一行文字說明它是什麼。

   範例（格式示意，實際路徑以當下解析為準）：

   動畫總目錄：
   ```text
   <磁碟>:\<repo>\projects\<主題>\index.html
   ```
   線上網址：
   ```text
   https://<GitHub 組織>.github.io/<repo>/<子路徑>/
   ```
3. **交接檔**：檔案清單、證據、收據、網址都照第 2 點；preflight 指令的 `cd` 也寫絕對路徑，讓接手方複製就能跑。
4. **範圍界線**：這條規則管的是「給人看、要點擊或複製的位置」。下列情況仍用相對路徑：可攜規範與 Skill、計畫書拓樸圖、程式碼內部的資源引用（見 `brain/error-log/2026-05-31-spa-relative-path-and-deploy-branch-mismatch.md`：SPA 資源要用 `./`）、推上公開 repo 的對外文件（不洩漏本機路徑）。
5. **指令也一鍵複製（2026-10-19 使用者要求）**：若使用的控制台外掛會把回覆裡的程式碼區塊做成複製按鈕，依下列格式讓按鈕可辨識。
   - 單行指令：一個區塊只放一行，例如 `/rename …` 的按鈕標籤是 `rename`、其他單行取前兩個字。
   - 多行區塊：第一行寫 `# 標題`（例如 `# 本機測試`），按鈕標籤就是標題，複製內容不含標題行；沒有標題時標籤只會是「指令（N 行）」，使用者分不出是哪一塊。
   - 區塊裡只有一個路徑或網址時，照第 2 點，路徑按鈕已涵蓋。
6. **規範同步**：`AGENTS.md` 對應條文由使用者在可寫治理檔的宿主套用；不在無寫入權的宿主硬改治理檔。
