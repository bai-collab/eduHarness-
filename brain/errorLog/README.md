# errorLog — 同一個坑不踩第二次

放**已驗證**的失敗、根因，以及一條可以直接照做的 Do Not Repeat。

重點在「已驗證」。猜測的原因不要寫進來，否則下次會照著錯誤的結論避錯路，比沒記錄還糟。

## 什麼時候寫

- 任務失敗，而且已經查清楚為什麼。
- 同一個錯誤重複發生第二次。
- 修好之後才發現原本的判斷方向就是錯的。

不用寫：一次就修好的筆誤、環境暫時性問題、還沒查清楚原因的失敗（先查清楚再寫）。

## 怎麼寫

複製 `TEMPLATE.md`，檔名用 `YYYY-MM-DD-簡短描述.md`。寫完在 `brain/wiki-index.md` 補一行索引。

本目錄目前是空的。你新增的檔案不會被 `git pull` 刪除；但本檔與 `TEMPLATE.md` 屬於內建檔，更新時會被覆蓋，別直接改它們。
